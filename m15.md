### M15 — Integrasi Multi-Provider (NVIDIA Nemotron Selector)

**Tanggal:** 2 Juli 2026
**Status:** 🏗️ Draft / In-Progress

#### Ringkasan
Menambahkan **NVIDIA Nemotron** sebagai opsi model selector premium di aplikasi. Integrasi ini berjalan secara *multi-provider* bersama KIE.AI. Pengguna dapat memilih model via *Model Selector* (M3), dan sistem akan secara otomatis melakukan *routing* ke endpoint yang tepat (KIE.AI atau NVIDIA).

#### Alur Kerja (Workflows)

1.  **Model Discovery**:
    * List model di `lib/core/constants/ai_models.dart` diperluas dengan menambahkan entry untuk `nvidia-nemotron-3-ultra`.
    * Setiap model memiliki field `provider` (Enum: `kieAI` atau `nvidia`).
2.  **Request Routing**:
    * `AiClientService` menggunakan *Provider Factory Pattern*.
    * Saat `sendMessage` dipanggil, service memeriksa `selectedModel.provider`.
    * Jika `kieAI` → hit endpoint `/claude/v1/messages`.
    * Jika `nvidia` → hit endpoint `/v1/chat/completions` milik NVIDIA (menggunakan `enable_thinking: true` sesuai spesifikasi model).
3.  **API Key Management**:
    * Mendukung *rotasi API key* (M4) untuk kedua provider.
    * Key NVIDIA di-inject via `AI_NVIDIA_API_KEY` (Secret baru di GitHub).
4.  **Interaction Style (NVIDIA Specific)**:
    * Model NVIDIA mendukung *Thinking Process*. Pada UI, blok `reasoning_content` akan dirender dengan UI khusus (teks abu-abu di dalam box *collapsible* "Proses Berpikir") sebelum konten utama muncul.

#### Perubahan Struktur Kode

* **`lib/core/constants/ai_models.dart`**:
    * Tambah enum `AiProvider { kieAI, nvidia }`.
    * Tambahkan model NVIDIA ke `kAiModels` dengan `apiModelId: "nvidia/nemotron-3-ultra-550b-a55b"`.
* **`lib/services/ai_client_service.dart`**:
    * Update method `streamMessage` untuk melakukan percabangan logika berdasarkan `provider`.
    * NVIDIA membutuhkan `extra_body` yang berisi `{"chat_template_kwargs": {"enable_thinking": true}, "reasoning_budget": 16384}`.
* **`lib/features/chat/widgets/message_bubble.dart`**:
    * Tambah `ReasoningBlock` widget untuk menangkap dan menampilkan `reasoning_content` yang dikirim dari NVIDIA API.

#### Penggunaan (UI/UX)
1.  **Selector**: Buka *Model Selector* di Composer, pilih model NVIDIA yang memiliki label "NVIDIA Nemotron".
2.  **Interaction**: Kirim chat seperti biasa.
3.  **Thinking Display**: Jika model NVIDIA sedang aktif, aplikasi akan menampilkan box *Thinking* yang *streaming* secara real-time di atas jawaban akhir.
4.  **Error Handling**: Jika API Key NVIDIA belum diset atau salah, sistem akan otomatis melakukan *fallback* ke KIE.AI (atau menampilkan pesan error spesifik jika provider tidak ditemukan).
